# akan-name
#### A web application that calculates the day of the week you were born and displays your Akan name, 2026

#### By Pierrette d'or MUGANGU

## Description
This application takes a user's birthday (day, month, year) and gender, calculates the day of the week they were born using the Zeller's congruence variation formula, and determines their Ghanaian Akan name based on their gender and birth day.

## BDD (Behavior-Driven Development)
Behavior | Input Example | Output Example 
 User enters a valid birth date and gender / Day: 12, Month: 8, Year: 1998, Gender: Female / "You were born on a Wednesday. Your Akan name is: Akua!" 
 User submits form with an invalid day / Day: 35, Month: 5, Year: 2000 | Alert/Message: "Please enter a valid day between 1 and 31." 
 User submits without selecting gender / Gender: Empty / Alert/Message: "Please select your gender."
